## 实际运行 MoveIt Servo 的结果

这是安装的 Servo C++ 节点实际运行结果，不是另写一个 NumPy 求解器冒充 Servo。保留示例奇异性阈值 17/30、碰撞检查及 0.1 rad 关节边界裕量。

| 场景 | 输入 / 原始轨迹数 | 通过候选守卫 | 主要结果 |
|---|---:|---:|---|
| 合成闭环 X/Y/Z/Yaw，18 秒 | 360 / 359 | 359 | 无 Servo 警告，三轴持续前进 |
| 同一真实故障日志，约 83 秒 | 1261 / 1652 | 373 | 908 条按最近奇异性停止状态阻断，另 371 条上一许可目标步长拒绝 |
| 原故障姿态的合成闭环，6 秒 | 120 / 119 | 39 | 80 条奇异性停止，实际净位移为数值零 |
| 在法兰处加入模拟障碍，6 秒 | 120 / 119 | 41 | 78 条碰撞停止，实际净位移为数值零 |
| 3 秒后不再发布 Twist，6 秒 | 120 / 61 | 61 | 最后输入约 2.950 s，最后轨迹约 3.099 s，此后无继续输出 |

通过数量包括零速度保持候选，不等于运动成功次数。Servo 状态与轨迹话题异步，表中的分类使用回调时最近状态；回放中原 232 个失败输入处最近状态为 225 次奇异性停止、7 次无警告，不能把这些数字理解为严格逐次计算的根因分类。

当前 URDF 在旧 610 个规划周期的条件数为 319.84～628.23，中位 404.80；实际 Servo 也出现奇异性停止。新框架会明确阻止部分姿态中的运动，**不会自动把原任务姿态变为可行姿态**。未通过增大阈值放行。

### 连续性、误差与约束

条件较好姿态的合成闭环（关节目标包含 SDK 0.001° 整数量化）：

- 条件数约 11.35～11.58；最大相邻候选关节步长 0.0648°，候选相对测量最大约 0.104°。
- 最大声明关节速度 0.0362 rad/s，最大观测声明速度变化率约 0.266 rad/s²；均低于本轮独立守卫 0.15 rad/s 与 0.5 rad/s² 的限制。
- 关节位置违反 0；三个纯平移阶段未发现超过 1 µm 的反向步骤，横向漂移约 5～17 µm；纯平移阶段朝向参考误差最大约 0.0098°。
- Yaw 阶段参考跟踪误差最大约 1.22°。这包含模拟关节模型的滞后，不是实机朝向精度。
- 三个约 2.75 s 的平移测量窗口中，输入速度积分约 13.75 mm，模拟实际位移仅约 5.85 mm，残差约 7.9 mm。**说明已持续前进，但速度跟踪并未达到输入积分；不能靠这个结果宣称 SDK/固件跟踪已解决。**

真实日志回放中的原始候选仍有问题：最大位置差分速度约 0.34 rad/s，声明速度差分加速度峰值约 3.00 rad/s²，超过所设限制；部分瞬时前进投影为负。Butterworth 平滑不能当作硬加速度保证。独立守卫和 Servo 状态过滤保留这些拒绝，没有扩大阈值。

回放朝向参考误差最大约 5.66°：新候选未执行，实际测量仍是旧轨迹产生的记录，而新参考在停止时冻结。因此这不是“新策略实机漂移 5.66°”的证据，也不能反向认定闭环朝向保持已合格。原始位置/朝向残差与完整分布保存在 JSON。

371 条“上一许可目标步长”拒绝还受到开环回放性质影响：后续测量由旧控制器驱动继续变化，审计端保留的最近许可候选不会控制这些测量。这个现象应记录；把拒绝阈值调大来使回放全部通过没有验证价值。

- `No kinematics solver ... use inverse Jacobian` 是当前选定路径；没有 3D 传感器插件的日志表示未构建相机 Octomap，不代表注入的障碍/自碰撞检查被关闭。实桌面、相机支架仍需显式建模。
